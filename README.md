# sugevalReportes
Paquete en R para consumir los Servicios Web Externos de la Superintendencia General de Valores (SUGEVAL) de Costa Rica, publicados mediante protocolo OData. Permite obtener catálogos de entidades y sus estados financieros, gestionando la autenticación por token, el intervalo mínimo entre peticiones y la iteración por ventanas de seis meses.
